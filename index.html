B R O A M P

Winamp-style terminal player for Chrome. アイコンをクリックして小さなウィンドウで操作。

プレイヤーを開く

INSTALL EXTENSION

  1. Chrome で chrome://extensions を開く
  2. 右上の「デベロッパーモード」をオン
  3. 「パッケージ化されていない拡張機能を読み込む」
  4. このリポジトリのフォルダを選択する
  5. ツールバーのアイコンをクリックして小さなプレイヤーウィンドウを開く

右クリックからタブ / サイドパネルも開けます。再生はオフスクリーンで続くので、ウィンドウを閉じても止まりません。SLEEP に分数をセットすると終了時に自動停止し、残り 1 分から音量を下げ、最後にゴングが鳴ります。
