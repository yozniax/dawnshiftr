broamp

メモ付きのベッドサイド・ラジオ。スリープとホワイトノイズ付き。

プレイヤーを開く 拡張の入れ方

Install

  1. Chrome で chrome://extensions を開く
  2. 右上の「デベロッパーモード」をオン
  3. 「パッケージ化されていない拡張機能を読み込む」
  4. このリポジトリのフォルダを選択する
  5. ツールバーのアイコンをクリックして小さなプレイヤーウィンドウを開く

再生はオフスクリーンで続くので、ウィンドウを閉じても止まりません。各局にメモを残せます。スリープは残り約 15 秒でフェードし、英語の声で The time is up. と知らせます。

Features

station notes · Radio Browser · country browse
sleep timer (15s fade + voice cue) · white noise (low / mid / high)
bass / mid / treble · favorites · local files · stream URLs

Keys

Space  play/pause     m  station note     S  sleep
Enter  play cursor    M  noted stations   w  white noise
R      radio search   N  by country       f  favorite
?      shortcuts
