DAWNSHIFTR

Bedside radio. Station notes, sleep timer, live titles when the stream sends them.

Open player Install extension Privacy

Install as a Chrome extension

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Run npm run pack
  4. Load unpacked and pick dist/chrome
  5. Pin DAWNSHIFTr, then click the toolbar icon to open the player.

Playback continues offscreen. Right-click the icon for a window or tab. Store zip: dist/dawnshiftr-chrome.zip. The local preview at http://127.0.0.1:43187 is not the extension.
