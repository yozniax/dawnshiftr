DAWNSHIFTr

Bedside radio. Station notes, sleep timer, live titles when the stream sends them.

Open player Install extension

Install

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Load unpacked and pick this folder
  4. Click the toolbar icon. A YouTube tab in the browser starts here so you can set sleep.

Playback continues offscreen. On a YouTube tab, the toolbar icon plays that video here. Sleep fades in the last 15 seconds.

Keys

Space     play/pause          Shift+F  fav tab
Enter     play highlighted    Shift+T  stations
↑ ↓       move cursor         Shift+H  history
F / M / X fav / note / delete Shift+C  countries
S         sleep 10            Esc      fav / close
ℹ or ?    this list
