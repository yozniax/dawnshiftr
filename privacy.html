DAWNSHIFTR privacy

Last updated 5 September 2026. DoYoBe / DAWNSHIFTr.

DAWNSHIFTr can send anonymous usage stats so we can see which stations people favorite, which ones they listen to longest, rough location (country and city), and how often / how long each install is used. This is not tied to your name, email, or Google account.

What we collect

  • A random install ID stored on your device. It is not your identity.
  • Favorite stations (id, title, stream host).
  • Listen time per station (not the song title on the stream).
  • How many times this install is opened and total listen time.
  • Timezone and browser language.
  • Country and city, derived on the server from the network address of the request. That address is used only for this lookup and is not stored.

What we do not collect

  • Name, email, account, payment data.
  • Precise GPS.
  • Station notes you type.
  • Live track titles from the stream.

Opt out

Open the player, press ℹ or ?, and use Usage stats to turn this off. Events already queued on the device are dropped. Stats already received stay in aggregate form.

Terms

A separate terms-of-service document is not required to use this free player. A privacy notice is required if usage stats are on, including for a Chrome Web Store listing.
